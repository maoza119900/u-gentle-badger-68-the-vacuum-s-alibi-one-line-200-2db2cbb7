A Node 22 program (standard library only) that writes one line — a robot
vacuum's excuse for missing a spot — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> I did not miss that spot. My lidar classified that dust as a load-bearing wall, and I am not insured for demolition.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two consecutive runs produce byte-identical output (same SHA-256). No network,
no `Date.now`, no `Math.random`.
